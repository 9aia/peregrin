# Performance

Performance benchmarks for the TypeScript runtime are not yet available. This page will be regenerated once the benchmark suite is ported from the Python prototype.

## What will be measured

- Event throughput for `shell`, `python` (shell-out), and in-process custom drivers.
- Concurrency scaling with the parallel fan-out model.
- Overhead of `JsonStore` versus `MemoryStore` persistence.
- Runtime node injection overhead.
