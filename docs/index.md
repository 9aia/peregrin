# Peregrin

A Vite+ monorepo starter with TypeScript, Effect, and Bun.

This site is organised around the Diataxis documentation framework.

## Get started

- [Peregrin docs site setup](getting-started.md) — install dependencies and run this VitePress site.

## Agent Campaigns

Agent Campaigns are documented across four quadrants:

- [Tutorials](ac/tutorials/index.md) — learn by doing, step by step.
- [How-to guides](ac/how-to/index.md) — achieve a specific goal.
- [Explanation](ac/explanation/index.md) — understand why it works.
- [Reference](ac/reference/index.md) — look up facts and schemas.
