HTTP API ​

peregrin serve composes two route sets under one listener: the session routes (peregrin's integration surface) and the generic entity routes (the hypha substrate — /api/entities*, pairing, auth, push, fs). peregrin-hub exposes the same generic surface merged across nodes, plus /api/node-status.

Entities (generic substrate) ​

Kind-agnostic entity plane — sessions register as kind="sepia-session", campaigns as kind="campaign". Op kinds are namespaced (sepia.prompt, campaign.start, entity.delete); snapshot bytes are opaque end-to-end.

Event ingest ​

POST /api/events/inject is the authenticated write half of the event surface — external producers (the bupha CI worker's ci.job.completed emit, forge check runners, ops tooling) inject a typed event into the campaign engine. GET /api/events stays the read-only SSE feed.

  • Auth — the shared bearer gate: Authorization: Bearer <PEREGRIN_TOKEN> (or a paired sepia_… credential / sepia_token cookie); open on tokenless loopback like every other /api/* route.

  • Body — application/json, ≤ 64 KiB:

    json
    {
  "type": "ci.job.completed",
  "payload": { "job": "build", "result": "success" },
  "idempotencyKey": "job-1:success",
  "campaign": "camp-entity-id",
  "source": "bupha"
}

    type is required and non-empty (kind accepted as the Event wire alias); payload defaults to {}; source defaults to "api"; idempotencyKey (idempotency_key alias) dedups retries against a bounded ring — a replayed key answers {"ok": true, "deduplicated": true} without re-delivering; campaign scopes the fan-out to one kind="campaign" entity.

  • Fan-out — the event is cloned into the ingress channel of every running campaign entity (or the one named by campaign). Stale/finished runs and closed channels are skipped.

  • Responses — 200 {"ok": true, "delivered": <runs that accepted>} (delivered: 0 = accepted, but no campaign entity was running); 200 {"ok": true, "deduplicated": true} on a replayed key; 400 malformed body / missing type; 401 bad credential; 404 unknown scoped campaign; 413 over the body cap; 500 sink failure; 501 when the node has no campaign plane wired.

Auth and errors ​

Non-loopback nodes require Authorization: Bearer <PEREGRIN_TOKEN> (hub: PEREGRIN_HUB_TOKEN). Session-route errors are JSON { "error", "code" } — not_found, invalid, unknown_agent, locked (a live holder blocks the op; pass takeover), conflict, busy, internal. Generic entity-route errors use hypha's {error} mapping, not the session shape.
