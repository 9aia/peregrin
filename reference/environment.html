Environment ​

Every variable peregrin reads. PEREGRIN_* configures peregrin itself; SEPIA_* vars are consumed by sepia binaries (the session-plane child and its drivers) — those are documented in sepia's reference.

Node (peregrin serve) ​

VariableDefaultMeaning
PEREGRIN_HOST127.0.0.1Bind address for /api/* + SSE
PEREGRIN_PORT8787Bind port (legacy PORT also read)
PEREGRIN_TOKEN—Bearer auth; required on non-loopback binds
PEREGRIN_HOME~/.local/share/peregrinNode data dir (identity, meta, tokens)
PEREGRIN_NODE$PEREGRIN_HOME/node.jsonStable node-identity file
PEREGRIN_NAMEhostnameDisplay name for GET /api/node
PEREGRIN_META / PEREGRIN_META_PATH$PEREGRIN_HOME/meta.jsonOverlay store (pins, archives, spans)
PEREGRIN_ORIGINSlocalhost:3000 ×2CORS allowlist; * echoes any origin
PEREGRIN_CLINE_DIR~/.cline/dataCline store dir — the convert target
PEREGRIN_CLAUDE_DIR~/.claudeClaude dir — file-history restore
PEREGRIN_SESSION_PLANEservicelocal/inprocess links sepia in-process (dev)
